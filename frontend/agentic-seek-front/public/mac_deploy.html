AgenticSeek macOS Deployment Guide

This guide provides step-by-step instructions for deploying AgenticSeek on macOS using our automated deployment script.

Step 1: Clone the Repository

git clone https://github.com/chalizardking/agenticSeek.git
cd agenticSeek

Step 2: Switch to the Deployment Branch

git checkout devin/1746498410-mac-deployment-implementation

Step 3: Run the Deployment Script

chmod +x scripts/mac_deploy.sh
./scripts/mac_deploy.sh

This script will:

  • Check and install all required dependencies
  • Configure the environment for macOS
  • Set up Ollama and download the recommended model
  • Start all required services
  • Provide instructions for running the application

Step 4: Run AgenticSeek

After the deployment script completes, you can run AgenticSeek using either:

CLI Interface (recommended for first-time use):

source agentic_seek_env/bin/activate
python3 cli.py

Web Interface:

source agentic_seek_env/bin/activate
python3 api.py

Then open http://localhost:3000/ in your browser.

Note:

The deployment script is designed specifically for macOS and handles all the necessary dependencies and configuration automatically. If you encounter any issues, please refer to the troubleshooting section in the deployment script.

Verification

Test the installation with the following queries:

  1. Basic functionality: Hello, what can you do?
  2. Web browsing capability: Search the web for the current date and time in Paris.
  3. Coding capability: Write a simple Python function to calculate the factorial of a number.

For more information, visit the AgenticSeek GitHub repository.
